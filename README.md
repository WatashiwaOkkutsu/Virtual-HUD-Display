# Virtual-HUD-Display
This project is a Python-based real-time Heads-Up Display (HUD) system that overlays graphical elements on a webcam feed using OpenCV and MediaPipe.

The system tracks facial landmarks and anchors visual components such as eye rings, labels, and indicators directly to the user’s face while also rendering fixed interface panels on the screen.

It demonstrates real-time computer vision processing, landmark detection, and dynamic UI rendering using Python.

Features:
- Face tracking using MediaPipe Face Mesh
- Face-anchored HUD elements (eyes, labels, indicators)
- Screen-fixed UI panels (system status, diagnostics, schematics)
- Real-time video processing with OpenCV
- Modular rendering functions for different HUD components

Tech Stack:
- Python 3.10
- OpenCV
- MediaPipe
- NumPy

Purpose:
Built as a learning project to explore real-time computer vision, facial landmark tracking, and overlay-based UI systems.
